# ADR-002：团队知识库平台重构基线与迁移边界

- 状态：已批准，作为 `refactor-team-knowledge-base-platform` 的实施基线
- 日期：2026-08-03
- 关联变更：`add-team-knowledge-base-rag`、`refactor-team-knowledge-base-platform`
- 适用环境：当前 macOS 本机；外部模型、视觉和向量协议仅以本机回环测试服务验证

## 已批准的调整

1. 新知识工作台必须从普通用户任务重新设计。现有 `src/pages/knowledge/index.tsx` 只可用于核对已有业务能力、API 和数据，**不得**作为导航、布局、字段顺序、步骤、文案、状态或交互测试的参考。
2. `/knowledge` 保持地址兼容，但正常入口只能进入新引导或项目工作台；旧页面如保留，只能在独立回滚开关后访问。
3. 所有验证只要求在当前 macOS 本机完成。Windows、Linux、真实禅道实例和真实外部 AI/视觉/向量服务不构成本变更的完成门槛。
4. 数据库、Command 和 TypeScript API 采用前向迁移与兼容门面；禁止清库、删除旧表或清空索引完成重构。

## 当前事实与差异

## 公共契约矩阵

| 领域 | 当前稳定 Command/API 外观 | 新契约规则 |
| --- | --- | --- |
| 项目与版本 | `list/upsert/delete_knowledge_project`、`list/upsert/delete_knowledge_release` | `id` 保持数字；新增版本清单 DTO 使用 camelCase，并明确 `null` 与缺失区别 |
| 来源 | `upsert_knowledge_source`、`upsert_knowledge_sources_atomically`、同步与范围预览 | `versionStrategy` 缺失时默认 `latest`，仅接受白名单枚举；远程处理必须显式授权 |
| 文档 | 列表、详情、版本、片段、比较、引用、`upsert/delete_knowledge_document` | 草稿不能进入搜索和问答；提交版本不可变，恢复生成新版本 |
| 检索与问答 | `search_knowledge_fts`、`search_knowledge_hybrid`、`ask_knowledge` | 先项目/版本硬过滤；返回可打开的稳定引用；证据不足必须拒答 |
| 代码分析 | 快照、分析、报告、文件、元素、调用图与影响分析 Command | 仅从 Git 对象读取；分析草稿与人工确认文档分离 |
| 向量与任务 | Profile 生命周期、向量搜索、任务查询/取消/重试 | 向量和活动配置始终本地持久化；重复请求必须复用活动任务或返回明确冲突 |

## 新工作台的六条主流程与字段分级

| 主流程 | 线性步骤 | 必填 | 推荐默认 | 按需确认 / 高级设置 |
| --- | --- | --- | --- |
| 创建项目 | 创建项目 → 选择仓库 → 选择版本 → 确认同步 | 项目名称、至少一个仓库 | 项目别名、默认分支、共同 Tag | 仓库角色、逐仓库覆盖、排除规则 |
| 上传文档 | 选择文件 → 确认项目/版本 → 上传 | 文件、项目 | 标题、文档类型 | 可见范围、解析策略、跨版本范围 |
| 编写文档 | 新建草稿 → 编辑 → 提交 | 标题、正文、项目 | 文档类型 | 父版本、标签、敏感级别 |
| 搜索知识 | 输入关键词 → 打开结果 | 关键词 | 当前项目/版本 | 仓库、类型、来源、检索通道 |
| 分析代码 | 选择快照 → 查看证据 → 编辑草稿 → 确认入库 | 项目版本、仓库范围 | 推荐分析范围 | Provider、模板、规则覆盖 |
| 配置与问答 | 选择本地推荐 → 确认构建 → 直接提问 | 项目/版本、问题 | 可用本地模型、对话 Provider | 远程授权、上下文预览、检索诊断 |

中文术语统一使用“项目、仓库、版本、文档、引用、代码元素、正在处理、查看详情”。不得在主界面直接使用未解释的 `Profile`、`fingerprint`、`dimension`、`Commit SHA` 或 `checkpoint`。

## 发布开关

功能开关及阶段名称固定为：`catalog`（目录）、`documents`（文档）、`ingestion`（异构解析）、`search`（搜索）、`analysis`（分析）、`graph`（图谱）、`embedding`（向量）、`qa`（问答）。每项支持按项目启用；默认关闭远程向量、远程视觉和远程分析。旧页面只允许由独立 `legacy_ui` 回滚开关启用。

## 不作为完成证据的内容

- 旧知识库页面的任何布局、步骤、字段顺序、文案或快照测试。
- Windows/Linux 检查、真实禅道项目同步、真实外部模型服务调用。
- 仅有构建成功、单元测试通过或截图，未验证本机文件、IPC、索引、引用和真实新流程的结果。
