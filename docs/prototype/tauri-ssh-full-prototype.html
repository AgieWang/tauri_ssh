14 JumpServer / 堡垒机会话兼容

覆盖国家电网 ISC 登录场景：只接入会话能力，不绕过鉴权。

设计边界：不抓 Cookie、不解析浏览器缓存、不获取目标服务器明文凭据。只支持授权资产同步、Web SSH 嵌入、连接令牌/网关模式预留。
Web SSH 嵌入ISC 登录

用户在官方页面完成登录和授权。

资产同步授权列表

仅展示当前用户有权限的服务器。

AI 能力建议-only

解释输出和生成命令，由用户确认发送。

18 空状态与错误状态

覆盖无数据、失败、未配置和安全拦截。

空状态

还没有服务器

连接失败

Host key changed
