# 10 本地/远程向量化与本地存储确认

- 状态：Proposed
- 对应用户需求：9

## 1. 推荐架构

Embedding Provider 只负责把文本转换为向量；文本片段、向量、Profile、激活状态、构建记录和评测结果始终保存在本地 SQLite。远程向量数据库不在首期范围。

## 2. 两种模式

### 本地推荐

- 默认优先，离线可用。
- 自动检测运行时、模型文件、维度和可用内存。
- 模型缺失时显示导入/下载指引，不自动切换远程。

### 远程自定义

- 默认关闭，选择具备 embedding 能力的已登记 Provider。
- 使用 Safe Credentials 引用，不保存或返回 Token。
- 每次构建前展示文档数、字符数、项目/版本范围和敏感阻断。

## 3. Profile 指纹

Profile 指纹至少包含：Provider 类型、模型与修订、维度、文本前缀、归一化、距离算法、解析器/规范化版本、分块配置和项目版本绑定规则。同维度不同模型不得复用向量。

## 4. 构建生命周期

```text
准备 → 估算 → 构建候选索引 → 校验维度/覆盖/质量
    → 原子激活 → 保留上一活动版本 → 可回滚 → 过期清理
```

构建失败或取消不得破坏当前活动向量。增量构建仅复用内容哈希和完整指纹均一致的片段。

## 5. 检索策略

在项目/版本硬过滤后进行向量召回。首期继续使用 SQLite + Rust 余弦计算；只有代表性规模 P95 证明不足时才评估 ANN/HNSW，ANN 也必须是可重建派生索引。

## 6. 当前状态

旧知识模块已有 Profile、向量、蓝绿构建和检索基础；新文档版本/项目版本绑定、完整指纹、任务统一和授权回归仍待收口。过去本地模型/ONNX 可用性存在环境限制，因此本次不能把静态通过视为本地推理已验收。

## 7. 验收标准

- 本地向量化完成后断网仍可搜索，且所有向量可在本地库核对。
- 远程 Provider 只收到经过授权和过滤的最小文本批次。
- 维度异常、部分响应、限流、超时和取消不激活失败索引。
- 切换 Profile 后可比较质量并一键回滚。
- 无向量时标题/全文搜索继续可用。

## 8. 请确认

- **C10-1（推荐）**：本地优先，远程默认关闭且不自动降级。
- **C10-2（推荐）**：所有向量和活动元数据始终存本地 SQLite。
- **C10-3（推荐）**：使用蓝绿构建、校验后原子激活并保留回滚。
- **C10-4（推荐）**：首期不引入远程向量库或 ANN，先以真实性能证据决定。
- **C10-5（待选择）**：本地默认模型是否继续以 384 维多语言 E5 系列为推荐基线？推荐保留为候选，不在需求阶段锁死具体模型。
