# 14 安全、权限与审计确认

- 状态：Proposed
- 对应用户需求：2、5、9、10 及所有外部/文件能力

## 1. 保护资产

- Git 仓库代码与历史。
- 内部需求、设计、测试、数据库和配置文档。
- AI/Git/SSH/数据库凭据。
- 本地向量、问答上下文、分析草稿和审计记录。
- 用户选择的本地文件及应用数据目录资产。

## 2. 信任边界

WebView、IPC 参数、文件路径、上传内容、Git 路径、HTML/SVG、远程响应和模型输出都视为不可信。前端校验只用于体验，Rust 必须再次校验范围、长度、格式和授权。

## 3. 四阶段控制

### 读取

只允许已登记 Git 工作区、用户明确选择的文件或授权目录。规范化路径并阻止 `..`、符号链接逃逸、设备路径和超限输入。

### 落盘

使用内容寻址资产、原子复制、最小权限和临时清理；SQLite/日志/错误不保存绝对外部路径或秘密正文。

### 远程

远程 Embedding、视觉/OCR、代码分析和问答分别授权。校验系统开关、来源授权、文档敏感级别、内容检测、Provider 能力、HTTPS/host 策略、重定向、超时和响应大小。

### 输出

搜索、问答、图谱、导出和 MCP 再做项目/版本/权限/敏感过滤。引用不返回凭据、连接串或内部秘密。

## 4. Git 与凭据

- Git 分析只读，不执行 checkout、stash、reset、clean、pull、push、Hook 或代码。
- 凭据只用 Safe Credentials/系统密钥链引用，前端和知识库只保存引用 ID/掩码状态。
- Provider URL 使用 HTTPS 和 host allowlist；回环测试服务作为本机验收例外。

## 5. 敏感检测

在持久化、远程发送、搜索、问答、MCP 和导出前检测私钥、Token、密码、连接串、凭据文件和 restricted 内容。命中后默认保存路径、哈希、规则和阻断结果，不保存秘密正文。

## 6. 审计事件

审计项目/仓库配置、上传、删除/恢复、远程发送、分析确认、Profile 激活/回滚、关系确认、MCP 调用和问答引用。记录主体、动作、目标引用、结果、时间、关联 ID 和安全摘要，不记录完整正文或请求头。

## 7. MCP 边界

默认只读暴露项目、版本、搜索、文档、图谱、引用和问答。写文档、确认关系、触发远程处理和任何 Git 写入必须是独立受控操作，首期可不开放。

## 8. 验收标准

- 合法和越权路径分别验证允许/拒绝。
- 恶意 URL、重定向到 loopback/link-local/metadata、超大响应和超时被阻断。
- 日志、错误、UI、数据库、测试产物中搜索不到秘密。
- 解析 HTML/SVG/Office 时不执行脚本、宏、外链或公式。
- 远程处理失败不会自动切换到未授权 Provider。

## 9. 请确认

- **C14-1（推荐）**：所有远程能力默认关闭并分别授权。
- **C14-2（推荐）**：知识数据库和前端只保存凭据引用，不保存秘密。
- **C14-3（推荐）**：MCP 首期只读，写能力另行审批。
- **C14-4（推荐）**：敏感命中默认阻断，不做自动不安全降级。
- **C14-5（待选择）**：是否允许用户在单次操作中临时授权远程发送？推荐允许一次性授权，并显示范围/字符量/Provider，默认不记住。
