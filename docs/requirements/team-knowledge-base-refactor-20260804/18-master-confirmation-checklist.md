1. 把用户调整回写到对应专题文档并将状态从 Proposed 改为 Accepted。
2. 对照当前 OpenSpec 和任务清单生成逐文件实施任务，不直接复用过期 v36 基线。
3. 先完成 P1 已有代码的契约、运行时和浏览器收口，再进入未实现域。
4. 每个阶段单独交付测试、运行时、数据库、浏览器、安全和性能证据。
