# 经验资产审计与模板

仅在显式 `/exp review` 或写入预览需要时读取。

## 审计维度

| 维度 | 检查方法 | 输出 |
|---|---|---|
| 过时 | 路径/符号/版本是否仍存在，外部事实是否可复核 | 保留、更新建议或归档建议 |
| 重叠 | 多个 Skill/规则是否覆盖相同强触发和正文 | 合并/收窄建议，不自动删除 |
| 孤岛 | 经验文档是否长期无引用且无可发现入口 | 增加索引或归档建议 |
| 漂移 | 规范源与镜像、README 与实现是否不同 | 指向同步工具和差异 |
| 敏感 | token、密码、密钥、PII、客户数据 | 立即停止输出原文，建议安全处理 |
| 无效 Why | 只有结论，没有原因、范围或证据 | 补证据或建议移除 |

审计默认只读。生成报告、修改或归档资产都需要用户再次确认目标。

## 候选预览模板

```markdown
## 候选 #N：标题

- 类型：①～⑥
- 原始证据：文件/commit/测试/用户明确规则
- Why：为什么值得长期复用
- 适用范围：仓库、模块、平台、版本
- 失效条件：何时需要复核
- 建议目标：绝对或仓库相对路径 + 章节
- 敏感性：无 / 已脱敏 / 不可沉淀

### 写入预览
...
```

## 会话摘要模板

只有用户明确要求写经验摘要时使用：

```markdown
# 经验沉淀摘要

- 仓库模式：...
- 扫描范围：...
- 识别候选：...
- 用户确认写入：...
- 跳过：...

## 已写入
| 候选 | 类型 | 目标 | Why | 验证 |
|---|---|---|---|---|

## 未写入
| 候选 | 原因 |
|---|---|

## 反哺候选
...
```

## 防腐化

- 每次最多推荐 10 条；其余仅计数，不自动创建 raw observations。
- 连续被跳过的候选不自动写 ignore 文件，除非用户明确要求维护忽略列表。
- 先读最近摘要去重；相同经验应补证据或更新原条目，而非重复追加。
- 易漂移事实写“截至日期 + 复核入口”，不要固化临时 PID、端口占用或短期服务状态。
- 每次写入都记录来源和 Why，但不复制完整敏感日志。

## 回滚

- 写入前保存目标文件 diff 或可恢复 patch。
- 若验证失败，只撤销本次目标段；禁止 stash、reset、checkout 或 clean。
- 规范源与镜像不一致时先停下报告，不用手工覆盖镜像修“表面一致”。
- 已 push 或外部发布的资产不在本工作流中自动撤回，需用户明确授权相应外部操作。
