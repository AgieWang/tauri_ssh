# 故障症状分流参考

## Tauri IPC

| 症状 | 优先检查 |
|---|---|
| `invoke` 找不到命令 | `generate_handler!` 注册、模块导出、命令 snake_case 名称 |
| 参数反序列化失败 | TS/Rust 字段、camelCase 转换、可空性、数值范围 |
| 调用长时间无响应 | 同步阻塞、锁等待、子进程、网络超时、事件监听 |
| 返回内容为空/错误 | Command 返回类型、错误转换、序列化、前端解包逻辑 |

## React 页面

| 症状 | 优先检查 |
|---|---|
| 页面空白 | 首个控制台异常、路由、懒加载、ErrorBoundary |
| 状态不刷新 | Hook 依赖、闭包、Zustand selector、异步竞态 |
| 重复请求/监听 | StrictMode、effect 清理、unlisten、订阅生命周期 |
| 样式或交互异常 | DOM 状态、CSS token、Ant Design props、遮罩层 |

页面诊断必须在 Codex 内置浏览器或 Control Chrome 中完成，不只看源码。

## Rust 后端

| 症状 | 优先检查 |
|---|---|
| panic/崩溃 | `unwrap`/`expect`、数组边界、毒化锁、FFI/unsafe |
| 间歇失败 | 竞态、锁范围、异步取消、共享状态生命周期 |
| 只在某平台失败 | 路径、权限、编码、子进程参数、平台条件编译 |
| 错误信息丢失 | `map_err`、日志上下文、Command 边界字符串化 |

## SQLite

| 症状 | 优先检查 |
|---|---|
| 列/表不存在 | `PRAGMA user_version`、迁移顺序、实际 DB 路径 |
| 数据重复/缺失 | 唯一约束、事务、游标/分页条件、并发写入 |
| database is locked | 事务时长、连接共享、写并发、忙等待配置 |
| 类型或枚举异常 | 真实 DDL、历史数据、NULL、序列化与映射 |

## 构建与测试

| 症状 | 优先检查 |
|---|---|
| Rust 编译错误 | 第一条编译器错误、feature、版本，再转 `rust-fundamentals`/resolver |
| TypeScript 类型错误 | 最先出现的类型不匹配、生成类型、API 契约 |
| 测试单独过整套失败 | 共享状态、执行顺序、端口/文件/数据库隔离 |
| 测试偶发失败 | 时钟、随机数、异步等待、资源竞争、外部依赖 |
