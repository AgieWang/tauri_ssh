## Purpose

定义知识平台的路径、凭据、远程模型、敏感内容、Git、MCP 和审计安全边界，确保内部文档与代码默认只在明确授权的最小范围内读取、存储和输出。

## ADDED Requirements

### Requirement: 确保秘密信息不进入知识数据
系统 MUST 使用安全凭据存储保存 Git 和 AI Provider 秘密，知识数据库、前端、日志、错误、引用和导出中只能出现凭据引用或掩码状态。

#### Scenario: 配置远程服务商
- **WHEN** 用户选择已有安全凭据用于远程模型
- **THEN** 知识配置仅保存凭据引用，查询接口不得返回 Token 或请求头明文

### Requirement: 强制限制文件访问范围
系统 MUST 只读取已登记 Git 工作区、用户选择文件或授权目录内的内容，并 SHALL 在 Rust 信任边界校验规范化路径、符号链接、大小、格式和允许操作。

#### Scenario: 符号链接越过来源根目录
- **WHEN** 文档或仓库条目通过符号链接指向授权根目录之外
- **THEN** 系统拒绝读取并记录不含目标正文的安全事件

### Requirement: 保持 Git 分析只读
系统 MUST 不因同步或分析执行 checkout、stash、reset、clean、pull、push、Hook、构建、测试、脚本或二进制。

#### Scenario: 仓库包含可执行安装脚本
- **WHEN** 扫描发现安装或构建脚本
- **THEN** 系统仅在格式和策略允许时读取其文本，不执行脚本

### Requirement: 控制每次远程内容传输
系统 MUST 分别控制远程 Embedding、远程视觉/OCR 和远程问答/分析，并 SHALL 在发送前校验系统开关、来源授权、敏感级别、内容检测、Provider 能力和目标主机策略。

#### Scenario: 远程处理未获授权
- **WHEN** 任一必要授权条件不满足
- **THEN** 系统拒绝发送且不自动切换其他远程 Provider

### Requirement: 检测并隔离敏感内容
系统 SHALL 在持久化、远程发送、搜索结果、问答上下文、MCP 和导出前检测私钥、Token、密码、连接串、凭据文件和 restricted 内容，并 SHALL 按策略阻断或脱敏。

#### Scenario: 在仓库中检测到私钥
- **WHEN** 扫描命中私钥规则
- **THEN** 系统默认只保存路径、哈希、规则和阻断结果，不保存或发送秘密正文

### Requirement: 审计敏感操作且不泄露内容
系统 SHALL 审计项目/仓库配置、上传、删除/恢复、远程处理、分析确认、Profile 激活/回滚、图谱关系确认、MCP 访问和问答引用，但 MUST 不记录秘密或完整敏感正文。

#### Scenario: 远程分析完成
- **WHEN** 一次远程代码分析完成
- **THEN** 审计记录主体、Provider、模型、项目/快照、字符量、引用数和结果，不记录发送的原始代码

### Requirement: MCP 默认保持只读
系统 SHALL 默认只通过 MCP 暴露项目、版本、搜索、文档、图谱查询、引用和问答等只读能力；写文档、确认关系或触发远程处理 MUST 使用独立受控操作。

#### Scenario: MCP 客户端尝试写入 Git
- **WHEN** MCP 客户端尝试通过知识工具修改仓库
- **THEN** 系统拒绝请求并保持只读边界
