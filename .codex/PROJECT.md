## 1. 项目背景

Tauri SSH 是面向 SSH 连接、远程主机管理和桌面运维工作流的 Tauri 桌面应用。

## 2. 项目专属技术栈差异

| 维度 | 框架默认 | 本项目 | 原因 |
|------|---------|--------|------|
| 待补充 | Tauri 2.x + React | Tauri 2.x + React | 初始化阶段沿用框架默认技术栈 |

## 3. 项目专属禁令

| # | 禁止 | 原因 / 替代方案 |
|---|------|---------------|
| 1 | 在前端持久化明文 SSH 密钥或密码 | 凭据必须走后端安全存储或系统密钥链能力 |

## 4. 项目专属命名 / 文件结构

初始化阶段沿用框架默认目录结构。新增 SSH 领域模块时优先保持 Command -> Service -> Database 分层。
