## 1. 项目背景

Tauri SSH 是面向 SSH 连接、远程主机管理和桌面运维工作流的 Tauri 桌面应用。

## 3. 准确性不变量

Skill 路由只能减少无关上下文，不能替代仓库证据或削弱验收：

1. 修改已有功能前，先读取真实参考代码并确认相关调用链。
2. Rust 后端保持 Command -> Service -> Database 分层；前端 `invoke` 统一封装在 `src/lib/api/`，TypeScript 类型与 Rust 模型对齐。
3. 涉及数据库 DDL 或数据格式时，先读取 `script/`、Nacos 等真实配置，再通过 Tauri SSH MCP 查询真实数据库。
4. 涉及前端页面时，必须使用 Codex 内置浏览器或 Control Chrome 验证真实页面。
5. 凭据、Git、服务器和数据库操作优先使用 Tauri SSH MCP，不暴露明文凭据。
6. 验证由实际变更文件和风险决定；交付前执行对应格式化、静态检查、测试、构建与 `git diff --check`，构建通过不等于完整验收。
7. 保留其他会话的未提交工作，不执行 stash、reset、跨分支切换、全量 add 或清理他者文件。

## 4. Skill 路由边界

- 路由器只提供候选 Skill 和风险提示，不直接决定实现方案；实现以当前源码、配置、数据库和运行时证据为准。
- 选择“最小完整集”：普通任务避免加载无关 Skill，跨层或高风险任务不设固定数量上限。
- 只把领域专有词或明确意图作为强触发；`设计`、`状态`、`文件`、`数据`、`检查`、`开发` 等宽泛词不能单独决定命中。
- 用户显式指定的 `/command`、`$skill` 或完整工作流优先；同一互斥组只保留一个最匹配的工作流，避免重复加载。
- 路由异常、清单缺失或进入 `fallback` 模式时，不阻断任务，退回已加载 Frontmatter 的极简评估流程。
- 被选中的 `SKILL.md` 必须完整读取；长 references 仅在入口指示或当前场景需要时读取。
