# 开发者文档输出模板

模板只提供结构。字段和结论必须来自 `source-scanning.md` 所列证据。

## Command/API 参考模板

```markdown
# {模块} Command 参考

## 范围与证据

- Rust Command：`{path}`
- 注册入口：`{path}`
- TypeScript API：`{path}`
- 验证状态：{静态确认/测试确认/运行时确认}

## `{command_name}`

用途：{基于注释和业务调用链的说明}

| 参数 | Rust 类型 | TypeScript 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `{name}` | `{type}` | `{type}` | 是/否 | {契约说明} |

- 返回：`{Rust type}` / `{TypeScript type}`
- 错误：{错误类型和可观察语义}
- 注入：{State/AppHandle/Window/无}
- 注册：{已注册/未注册}
- 前端封装：`{path}`
- 调用点：`{path}` 或“暂未发现生产调用”
- 权限：{Capabilities 或“无额外插件权限”}
```

## 增量更新保护

- 先读取现有文档，识别用户维护段落。
- 可使用稳定注释标记生成区，但首次添加标记不得包裹并接管未知手工内容。
- 仅更新请求范围内章节；不顺手格式化整份文档。
- 删除接口或字段时写明证据，避免仅因本次扫描未匹配就直接删除文档。
- 输出后检查相对链接、标题锚点、代码块闭合和表格列数。
