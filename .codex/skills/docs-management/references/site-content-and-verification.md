# VitePress 内容与验收

## 写作规范

| 维度 | 规则 |
|---|---|
| 受众 | 面向产品用户或管理员，避免暴露内部实现细节 |
| 语言 | 默认中文，术语保持项目一致 |
| 标题 | 单一 `#` 标题，主体使用 `##` / `###` |
| 示例 | 使用脱敏、可运行或明确标注为示意的数据 |
| 表格 | 用于配置、字段、权限和步骤速查 |
| 导航 | 每页提供必要的上一层或相关章节链接 |
| 图片 | 使用站点内相对路径；保留用户已有资源 |
| 能力状态 | 区分代码存在、测试通过、运行时验证和正式发布 |

不要求机械模仿旧站点的句式或表格密度；优先保持当前站点的一致结构、可读性和无障碍体验。

## 内容证据

站点页面应从当前源码、配置和已验证行为提取：

- 功能入口：真实路由、导航和页面。
- 操作步骤：真实交互顺序、校验和错误提示。
- 配置：真实字段、默认值、作用域和重启要求。
- Command/API：仅在面向用户确有必要时展示，不暴露内部敏感接口。
- 权限与安全：说明用户需要的权限，不公开凭据或内网拓扑。
- 截图：必须来自当前真实页面；遮盖账号、Token、服务器地址和业务数据。

如果没有运行时验证，使用“当前代码提供……”等限定语，不写“已支持”“可正常使用”等验收结论。

## 构建检查

在站点目录而不是主项目根执行现有脚本：

```bash
pnpm install
pnpm build
```

依赖已安装且锁文件未变化时，可跳过 install。不得为了修构建随意升级 VitePress 或全量重写 lockfile。

至少检查：

- VitePress 配置语法和导航链接。
- Markdown 标题、代码块、表格和相对链接。
- 未解析占位符、绝对本机路径和敏感内容。
- UTF-8 无 BOM、中文乱码和 `git diff --check`。

## 浏览器验收

前端页面测试强制使用 Codex 内置浏览器或 Control Chrome。构建通过不能替代页面验收。

验收最小集合：

1. 首页加载成功，浏览器控制台无阻断错误。
2. 主导航、侧边栏和本次修改的每个章节可访问。
3. 站内链接、锚点、代码块和表格正常展示。
4. 桌面和窄屏视口均无明显溢出或遮挡。
5. 搜索、深色模式或自定义主题等已启用能力可用。
6. 页面和静态资源没有泄露本机路径、内网地址、凭据或真实业务数据。

记录访问地址、验证页面和发现的问题。若本地服务不可启动，报告阻塞，不把静态检查称为真实验收。
